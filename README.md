# EvdoGuideAndroid2

تطبيق Android عربي مبدئي لمساعدة المستخدم على فهم قوة إشارة CDMA/EVDO واختيار أفضل مكان للجهاز أو الراوتر.

## الحالة الحالية

- مشروع Android/Kotlin قابل للفتح في Android Studio.
- واجهة عربية RTL باستخدام Jetpack Compose.
- شاشة رئيسية احترافية تعرض قراءة الإشارة الحالية عند توفر الصلاحيات.
- طبقة `SignalRepository` كبداية لقراءة نوع الشبكة وقوة إشارة CDMA من Android Telephony APIs.
- توضيح واضح أن تثبيت وضع EVDO/CDMA الحقيقي يعتمد على صلاحيات النظام أو Root حسب الجهاز.

## التشغيل

1. افتح المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. شغّل التطبيق على هاتف Android يدعم الشبكات المطلوبة.
4. امنح صلاحيات الموقع/الهاتف عند الطلب.

## أول خطوة تنفيذية قادمة

تنفيذ شاشة "خريطة القياس الداخلية":

- زر لحفظ قراءة الإشارة الحالية.
- اسم اختياري للمكان مثل: النافذة، السطح، الصالة، قرب الراوتر.
- تخزين `dBm`, مستوى الإشارة، نوع الشبكة، والتاريخ.
- ترتيب النقاط من الأقوى إلى الأضعف.
- إظهار توصية عملية: "أفضل مكان حالياً هو..."

بعد ذلك تأتي شاشة إرشاد EVDO/CDMA Mode Guidance، مع فصل واضح بين:

- إرشادات آمنة يستطيع المستخدم تنفيذها من إعدادات الهاتف.
- أوامر Root/Service Mode التي تحتاج تحققاً حسب موديل الجهاز ولا يتم تشغيلها تلقائياً بدون موافقة واضحة.
